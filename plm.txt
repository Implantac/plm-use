# PROMPT MESTRE — EVOLUÇÃO INTEGRAL DO USE MODA PLM

## 1. MISSÃO

Você está trabalhando sobre um projeto PLM para a indústria da moda.

Repositório atual:

https://github.com/Implantac/plm-use.git

O objetivo NÃO é reconstruir o projeto do zero.

O objetivo é transformar o projeto existente em um **PLM profissional, comercialmente vendável, operacionalmente claro, visualmente premium e fortemente integrado com Inteligência Artificial**, preservando a infraestrutura, funcionalidades, banco, workflows, componentes e regras de negócio que já estejam corretos.

A evolução deve acontecer sobre o projeto existente.

Não crie uma aplicação paralela.

Não substitua o projeto inteiro por uma demonstração.

Não simplifique removendo funcionalidades importantes.

Não transforme o sistema em um ERP.

---

# 2. NOVA DEFINIÇÃO DO PRODUTO

O produto deve ser entendido como:

## USE MODA PLM

### "Da ideia ao produto industrial. Em um único fluxo."

O sistema deve permitir que uma empresa de moda:

1. pesquise tendências;
2. crie coleções;
3. desenvolva novos produtos;
4. utilize IA como estilista;
5. gere conceitos visuais;
6. gere imagens de produtos;
7. transforme conceitos em referências;
8. desenvolva ficha técnica;
9. modele;
10. crie pilotos;
11. faça ajustes;
12. desenvolva engenharia;
13. defina materiais;
14. defina operações;
15. estime/calculе custos;
16. aprove o produto;
17. entregue o produto ao ERP;
18. acompanhe produção;
19. acompanhe qualidade;
20. acompanhe lançamento;
21. acompanhe desempenho;
22. utilize os resultados para melhorar próximas coleções.

O PLM deve ser o sistema de desenvolvimento e inteligência do produto.

ERP continua sendo o sistema transacional/administrativo.

Não duplicar desnecessariamente financeiro, fiscal, estoque, contas a pagar, contas a receber etc.
